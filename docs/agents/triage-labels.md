# Triage Labels

As skills falam em cinco papéis canônicos de triagem. Este arquivo mapeia cada papel para a string de label usada no tracker deste repo.

| Label in mattpocock/skills | Label in our tracker | Significado                                   |
| -------------------------- | -------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`       | Mantenedor precisa avaliar esta issue         |
| `needs-info`               | `needs-info`         | Aguardando mais informação de quem reportou   |
| `ready-for-agent`          | `ready-for-agent`    | Totalmente especificada, pronta para agente AFK |
| `ready-for-human`          | `ready-for-human`    | Exige implementação humana                    |
| `wontfix`                  | `wontfix`            | Não será tratada                              |

Quando uma skill mencionar um papel (ex.: "aplique a label de triagem AFK-ready"), use a string correspondente da coluna da direita.

Edite a coluna da direita para casar com o vocabulário que o repo realmente usa.
